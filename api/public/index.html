Tài liệu tích hợp API (Dành cho Auto/Tool)

API Server nội bộ cung cấp 2 Endpoint để các ứng dụng khác (MacroDroid, Auto Click, Script...) gọi thẳng vào mà không cần Internet.

GET /health

Kiểm tra trạng thái hệ thống và xác nhận model đã nạp vào bộ nhớ hay chưa.

curl http://127.0.0.1:5000/health
POST /solve-file

Giải mã CAPTCHA bằng cách tải lên file ảnh (PNG, JPG...). Sử dụng multipart/form-data với key là file.

curl -X POST -F "file=@/sdcard/captcha.png" http://127.0.0.1:5000/solve-file
POST /solve-base64

Giải mã CAPTCHA bằng chuỗi Base64. Chấp nhận cả dạng thô hoặc có prefix data URI.

{
    "image_base64": "iVBORw0KGgoAAAANSUhEUgAA..."
}

Mẫu kết quả trả về (JSON):

{
    "success": true,
    "captcha": "4KTN9",
    "inference_time_ms": 115.42
}
